What is BotHearth?

BotHearth browses websites, works with files and saves results on your Mac, Linux host or VM. Connect a supported model account, describe a task, and take control when needed. Model access is separate.

The project is independent of OpenAI, Anthropic, Docker, and other providers mentioned in the documentation. Their names identify integrations or dependencies and do not imply endorsement.

How can I help?

Try a small reproducible task and report the result. A clear issue with the expected behavior, actual behavior, commit, OS, runtime, model connection, and safe reproduction steps is more useful than a broad feature request.

For code changes, read CONTRIBUTING.md, the contributor agreement, and the licence first. Keep a change focused. Run the checks relevant to the code, include a reproducible failure when fixing a bug, and document changes to behavior or trust boundaries.

npm ci
npm run build
npm run typecheck
npm run lint

The full test instructions are in the contribution guide. Computer-server unit checks use their own dependency install; container integration checks need built images. Share sanitized logs only. Report vulnerabilities privately.
