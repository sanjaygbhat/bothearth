What is BotHearth?

BotHearth gives an AI agent a separate container-based computer and lets an operator follow the work, review requests, and take over its browser. It uses an installed model CLI or configured adapter; it does not provide model access or run a hosted agent service.

The name suggests a home for the agent's tools: a place for work that you can watch and inspect. Development began as ModelBot, which remains in some compatibility identifiers and earlier screenshots.

The maintainer is Sanjay Bhat. The project is independent of OpenAI, Anthropic, Docker, and other providers mentioned in the documentation. Their names identify integrations or dependencies and do not imply endorsement.

How can I help?

Try a small reproducible task and report the result. A clear issue with the expected behavior, actual behavior, commit, OS, runtime, model connection, and safe reproduction steps is more useful than a broad feature request.

For code changes, read CONTRIBUTING.md, the contributor agreement, and the licence first. Keep a change focused. Run the checks relevant to the code, include a reproducible failure when fixing a bug, and document changes to behavior or trust boundaries.

npm ci
npm run build
npm run typecheck
npm run lint

The full test instructions are in the contribution guide. Computer-server unit checks use their own dependency install; container integration checks need built images. Share sanitized logs only. Report vulnerabilities privately.
