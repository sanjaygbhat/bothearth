Meet BotHearth

An agent with its own computer.
The computer is yours.

Give BotHearth a task. It opens its own browser, works through the steps, and saves the result on your machine — while you watch. When a site needs a real person, you take the keyboard.

  • No vendor quota, no vendor VM. BotHearth runs on your Mac or Linux machine. It signs in to the Codex or Claude Code account on your plan. No BotHearth account to create, and no BotHearth quota to hit. Your own plan is the only ceiling. Codex is verified live. Claude Code is listed, not yet verified live.
  • It stops for you, not at you. It pauses when a site needs a password, one-time code, passkey, CAPTCHA, or card entry. BotHearth then hands you control. The model is frozen while you type and cannot see the screen. Turn on Settings → Ask before sensitive actions for extra checks before sending, uploading, deleting, paying, or new sites. Those checks stay off until you enable them.
  • Long work survives. Our recorded inbox test ran 51 minutes across two runs. It paused partway and picked the work back up. It created 18 filters, archived 21 conversations, and saved one report. Observed result, not a guarantee. See the recorded run and its timings.

MachineDaemon on your Mac, Linux host, or a VM you operate. Browser, shell, and proxy containers. No BotHearth-hosted agent account. Laptop sleep stops local work.

Review promptsOff by default. Optional Settings toggle Ask before sensitive actions reviews detected sends, uploads, deletes, checkout steps, and new-site form submits taken through BotHearth’s browser tools. Expand Sensitive actions to choose which gates fire and to set API-adapter max tool calls and spend cap (0 = no limit); native Codex and Claude Code tasks have no BotHearth cap. Native CLI shell and network tools bypass those checks. Detection is incomplete.
Credentials / takeoverPassword, OTP, passkey, CAPTCHA and payment-card fields pause for Take control. Checkout steps without a card field are optional review prompts. You type; the model is frozen and capture is blocked. Take control requests full screen; Esc leaves full screen without returning control. Passkeys generally fail inside the container browser.
StoppingStop ends the task. bothearth stop stops the daemon. There is no BotHearth quota. A task runs until it’s done, until you stop it, or until your own model plan hits its limit. Then it pauses and can resume. Closing the window is not Stop.
NetworkDefault: public web via the egress proxy. Strict mode restricts destinations. Policy is best-effort, not a firewall.
