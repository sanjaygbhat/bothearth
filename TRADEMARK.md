# Project name and branding

BotHearth is the public name selected for the project originally developed as ModelBot. The project does not claim a registered trademark or completed legal clearance. It is independent of OpenAI, Anthropic, Docker, and the other projects and providers named in the documentation.

## Using the project identity

Use the name factually when describing this project, compatibility, a contribution, or an identified fork. Do not imply that the maintainer or a model provider created, endorsed, or maintains your own product. A modified fork should use its own name and clearly explain its origin.

Copyright permission for project code and brand files comes from [LICENSE](LICENSE); it does not itself grant trademark rights. Third-party assets keep their own terms, including the Fraunces font license described in [NOTICE](NOTICE). Statutory rights of truthful reference are not removed by this policy.

Ask the maintainer before presenting the BotHearth name or cairn mark as your own product identity: [the contact form](https://bothearth.com/contact/). Do not add an ® symbol or describe another provider as a partner without an actual basis.

A domain registration, an empty search result, or this policy is not proof that a name is available under trademark law. Similar names, related products, and local rights can matter; see the [USPTO's clearance guidance](https://www.uspto.gov/trademarks/search/comprehensive-clearance-search-similar-trademarks).
